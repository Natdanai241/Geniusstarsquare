✦ จีเนียส สตาร์: กระดานดาวหกแฉก 48 ช่องสามเหลี่ยม • ช่องล็อก 7 • ชิ้นคริสตัล 11 • เติมให้เต็ม 41 ช่อง

ช่องล็อกถาวร = ช่องสีขาวมีรูปทั่งตีเหล็ก วางชิ้นทับไม่ได้

🎲 ก่อนเริ่มทุกรอบ: ลูกเต๋าเวทสุ่มตำแหน่งช่องล็อก แล้วทั่งจะลอยลงกระดานทีละอัน จากนั้นนับถอยหลัง 3–2–1 แล้ว GO!

การวาง: ลากชิ้นจากถาดลงกระดาน ห้ามทับกัน ห้ามทับช่องล็อก ห้ามออกนอกกระดาน

หมุน / พลิก: แตะชิ้นซ้ำในถาด = หมุนอัตโนมัติ ไปแนวถัดไปที่ใกล้ที่สุด หรือกดปุ่ม ↻ หมุน / ⇋ พลิก (คีย์บอร์ด: R / F)

เอาชิ้นออก: แตะชิ้นที่วางแล้วบนกระดาน หรือลากออกนอกกระดาน

ส่งคำตอบ: กด ✔ ส่ง เมื่อคิดว่าต่อครบแล้ว (ระบบตรวจให้อัตโนมัติด้วย)

คะแนนต่อรอบ (คิดจากช่องที่เติมจริง):
• ครบ 100% = 3 คะแนน • มากกว่า 95% = 2 คะแนน
• มากกว่า 80% = 1 คะแนน • 80% หรือน้อยกว่า = 0 คะแนน
